So geht's – am Kinder-Handy

  1. Handy neu oder auf Werkseinstellungen zurückgesetzt einschalten (Daten vorher sichern). Ihr seht „Willkommen“ / „Los geht's“.
  2. Sechsmal schnell auf eine freie Stelle mitten auf dem Bildschirm tippen. Samsung: auf eine leere Fläche über dem „Start“-Knopf tippen.
  3. Das Handy will ins WLAN – verbinden. Dann öffnet sich eine Kamera.
  4. Hier „QR-Code groß anzeigen“ tippen und mit 20–30 cm Abstand scannen. Hilft: Bildschirm heller, kein Spiegeln, Handy ruhig halten. Am Laptop/PC anzeigen ist leichter als an einem zweiten Handy.
  5. „Dieses Gerät gehört eurer Organisation“ → Weiter/Akzeptieren. FrohLock wird geladen und koppelt sich selbst.
  6. {% if template_name %}Die Einstellungen von „{{ template_name }}“ kommen automatisch.{% else %}FrohLock fragt nach Eltern-PIN, Schlafenszeit und Tageslimit.{% endif %} Dann „Weiter mit der Handy-Einrichtung“.

  4. FrohLock führt durch die Erlaubnisse: Über anderen Apps einblenden, Geräteadministrator, Benachrichtigungen, Akku.
