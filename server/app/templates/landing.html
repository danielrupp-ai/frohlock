Vom Handy steuern

Sperrzeiten und Limit jederzeit anpassen und die Nutzung live einsehen.

So einfach geht's

  1. Auf dem Kinder-Laptop diese Datei herunterladen und installieren (einmalig mit Admin-Rechten).
  2. In der Eltern-Verwaltung einen Kopplungscode erzeugen.
  3. Im Setup den Code eingeben, deinen PIN und die Sperrzeiten festlegen – fertig.
  4. PIN vergessen? Kein Problem – über PIN zurücksetzen per E-Mail.
Tipp für sicheren Schutz: Das Kind sollte ein Standard-Benutzerkonto haben (kein Administrator).
